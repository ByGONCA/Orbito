# CLAUDE.md

Guidelines for Claude and AI assistants working in the Orbito repository:

- **Core Principles & Guidelines:** See [`AGENTS.md`](./AGENTS.md) for Graphify, Ponytail simplicity ladder, anti-boxiness UI rules, and multi-agent roles.
- **Repository Organisation Policy:** Read and adhere strictly to [`docs/development/REPOSITORY_ORGANISATION.md`](./docs/development/REPOSITORY_ORGANISATION.md). Never place new markdown files or reports in the repository root.
- **Documentation Index:** Consult [`docs/README.md`](./docs/README.md) for the centralized index of all architecture, audits, and developer guides.
- **Verification Commands:** Run `npm run typecheck`, `npm test`, and `npm run validate:structure` before submitting work.
